# Job Analytics – Global Internship & Job Analytics

**Job Analytics** is an interactive data analytics and visualization project developed to analyze global job and internship market trends using a comprehensive job-posting dataset. The project uses **Tableau Public** to transform raw job data into interactive dashboards, charts, filters, and geographic visualizations.

The analysis focuses on key factors such as **hiring trends, salary ranges, work types, company size, qualifications, job opportunities, and regional hiring patterns**. Users can interact with the dashboards using dynamic filters to explore specific countries, industries, salary thresholds, job roles, and other job-related attributes.

The project consists of six major analytical modules: **Workforce Preferences, Company Scale & Opportunity, Internship Pay Landscape, India vs Germany, Top Hiring Companies, and Qualification Opportunity Map**. These modules provide different perspectives on the job market and help identify patterns in employment opportunities and compensation.

# Key Features

* Interactive Tableau dashboards and visualizations
* Dynamic filtering based on job-related attributes
* Salary distribution and compensation analysis
* Company size and hiring opportunity comparison
* Work type analysis including Remote, Hybrid, and On-site
* Geographic analysis using latitude and longitude
* Country-level job market comparison
* Qualification and education-based opportunity analysis
* Company benchmarking and hiring analysis
* Drill-down exploration from overall trends to specific job opportunities

# Technology Used

Tableau Public | Data Visualization | Data Analytics | CSV Dataset | Geographic Mapping | Calculated Fields

# Project Workflow

The project follows a structured analytical workflow: **Data Collection → Data Filtering → Data Analysis → Visualization → Interactive Exploration → Insight Generation.

Overall, Job Analytics demonstrates how data visualization and business intelligence techniques can be used to convert large-scale job-posting data into meaningful insights that support understanding of global employment trends, salary patterns, hiring activity, and qualification requirements.
